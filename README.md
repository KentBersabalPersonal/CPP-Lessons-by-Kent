# C++ Lessons by KentZel

Hello Po! This repository is where I'm documenting my journey learning C++ — one concept at a time. Each file focuses on a single topic, with simple, easy-to-follow code so I (and anyone else learning) can look back and understand exactly what's going on.

If you're also just starting out with C++, feel free to browse around, learn alongside me, or fork this repo for your own practice!

# What I've Learned So Far

### 🔤 The Basics
- `01-Hello-world.cpp` – My very first C++ program
- `02-Variables-and-Data-Types.cpp` – Storing and labeling data
- `03-Input-cin.cpp` – Getting input from the user
- `04-operators.cpp` – Math, comparison, and logical operators

### 🔀 Control Flow
- `05-Conditional-statements.cpp` – Making decisions with if/else
- `06-Switch.cpp` – Switch statements as an alternative to if/else

### 🔁 Loops
- `07-for-loop.cpp` – Repeating code a set number of times
- `08-while-loop.cpp` – Repeating code while a condition is true
- `09-do-while-loop.cpp` – Like a while loop, but runs at least once
- `13-Nested-loops.cpp` – Loops inside loops

### 🧩 Data Structures
- `10-arrays.cpp` – Storing multiple values in one place
- `14-2D-arrays.cpp` – Grids and tables of data
- `17-Vectors.cpp` – Resizable arrays that grow as you need them

### ⚙️ Functions
- `11-Functions.cpp` – Reusable blocks of code
- `12-function-prototype.cpp` – Declaring functions before defining them

### 🏗️ Structs, Pointers & Classes
- `15-Structs.cpp` – Grouping related data together
- `16-Pointers.cpp` – Understanding memory addresses (the scary but important stuff!)
- `18-Classes(Basic).cpp` – My first steps into Object-Oriented Programming
- `19-Constructor.cpp` – Setting up objects automatically when they're created
